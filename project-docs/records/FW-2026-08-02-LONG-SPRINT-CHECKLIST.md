# Flywheel long-sprint checklist

Date: 2026-08-02

Start condition: Task 0 and Task 1 remain exact-head green and the acceptance
recorder can produce both pass and fail receipts.

## Phase 1: Close the Flywheel governance spine

- [ ] Task 2: Make TADR tiering, control observations, envelope construction,
  fingerprints, infrastructure correlation, and legacy serialization fail
  closed. Use an installed Proof Surface wheel, not sibling-source imports.
- [ ] Task 3: Consolidate signature verification on the configured keyring;
  implement SQLite nonce/action accounting, append-only signed revocation
  import, external governance-state signing, verified boot loading, exact-scope
  classify/compliance/lane calls, and the frozen gateway file gate.
- [ ] Task 4: Repair Cloud IAM dual authorization and revocation truth; refuse
  untrusted Lean code without the pinned isolated sidecar; call the real native
  adapter or report unavailable; add the derived TADR schema and calibrated
  public research copy.
- [ ] Task 5: Harden the desktop Governance view against malformed/large data,
  add refresh and state tests, run Flutter analyze/test/Windows release build,
  and add the root CI gate.

Exit gate: Tasks 2 through 5 pass task-level spec and quality review. Missing,
malformed, stale, unsigned, untrusted, expired, revoked, wrong-scope, or
exhausted authority always denies before a product call.

  governed MCP replay, close stores reliably, and ship its owner manifest.
- [ ] Task 6B, Relay: make root and write/exec ceilings server-owned, use the
  process-owner Flywheel verifier, make injection probes side-effect-free,
  normalize provider errors, deepen receipt binding, and ship its manifest.
- [ ] Task 7A, Gather: repair the production adapter and owner manifest using
  real producer bytes.
- [ ] Task 7B, Crucible: map real status and complete-row digest.
- [ ] Task 7C, Index: emit the exact context-envelope command and preserve MATCH,
  DRIFT, and UNVERIFIABLE.
- [ ] Task 7D, Forum: map `gate_edited` and only observed event kinds.
- [ ] Task 7E, Learn: reconcile package/MCP version, 15-tool documentation,
  supported MCP launch, exports, adapter, and manifest.
- [ ] Task 7F, Telos: name six flagship servers, remove unimplemented transport
  claims, run launch/tool-exact freshness tests, and preserve private material.
- [ ] Task 7G, Flywheel/local-model: publish the seven-lane roster and make
  health evidence honest. A process without status/doctor is declared or stale,
  never live.
- [ ] Task 8: Load seven lane manifests plus Mneme, Relay, and Plexus through
  explicit paths, entry points, or the packaged lock; fail on collisions and
  unsafe commands; probe all ten components including Plexus itself.

Exit gate: isolated installed packages pass cross-language conformance without a
workspace-root assumption. Every owner manifest hash is locked and every health
result carries a typed receipt.

packages name exact source and lane hashes; reports preserve raw artifact paths,

keyboard, reduced-motion, contrast, clipping, overflow, and generated-hash gates
all pass. Private prospect/client material never enters a public projection.

## Phase 5: Integrate and close the recursive loop

- [ ] Run one final cross-repository trust, compatibility, privacy, benchmark,
  packaging, and public-claim review.
- [ ] Run all clean-worktree full gates through the acceptance recorder.
- [ ] Push remaining branches, open PRs, wait exact-head terminal CI, and merge
  with expected-head protection. Never force-push.
- [ ] Verify every live default SHA, version source, workflow artifact,
  repository-hosted page, checksum, and link target.
- [ ] Update the completion checklist, objective matrix, capability catalog,
  roadmap, experimental outcome, and next recursive loop from live receipts.
- [ ] Leave registry/model publication withheld at READY_TO_RELEASE unless the
  operator gives separate explicit authority.
- [ ] Mark the active goal complete only when every required output is live and
  no required repository has an open workflow PR or unreviewed workflow change.
