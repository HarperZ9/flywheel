# Flywheel Universal Harness and Rowan Agent Competitive Matrix

This document benchmarks **Flywheel** (as a universal AI coding/research harness) and **Rowan** (Flywheel's native agent runtime in `desktop/` and `harness/`) against leading coding harnesses and autonomous agent platforms. Every capability mark is tied to shipped modules and verification receipts in this repository; every open deficit is stated plainly with a concrete closure milestone.

---
