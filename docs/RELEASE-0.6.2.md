# Flywheel 0.6.2

Flywheel 0.6.2 brings the assistant, the model providers, and the work record together in the native app. Rowan is the named assistant and now runs operations through a shared operation host. Native model providers reach the workspace through a bounded tool bridge bound to your authenticated CLI identity. Agent traces stay private and owner-bound. Bulletin task evaluation runs through an independently observed bridge.

## Rowan operates Flywheel

The Flywheel assistant is named Rowan across the native surfaces. Rowan carries a procedural luminous companion rendered in the app, with the aperture material and palette tuned for the native view. Rowan's operation UI wires into a shared operation host, so a walkthrough and a real operation take the same admitted path rather than two separate code routes.

## Native provider protocol

A bounded native provider tool bridge lets a provider's own tools reach the workspace under explicit grants. The desktop renders those native agent tool protocol grants for review before they run. The Anthropic native models appear in the roster, native Codex model selection is honored, and Claude execution binds to your authenticated CLI identity. A supervised agent runs against a bound model workspace and an admitted execution budget.

## Private, owner-bound agent traces

Native agent traces stay private. Detail reads are owner-bound and authenticated, and agent history reads are bounded and authenticated before any content is returned. The desktop adds an authenticated private trace reader and private trace-backed captions, so the person who owns a run can inspect it while the trace is not exposed to other readers. Selected private source context enters an approved run without widening who can read it.

## Bulletin task evaluation

A bounded Bulletin model evaluation adapter runs task evaluation through an independently observed bridge with explicit evidence checks. Bulletin plaintext grants bind to the approved origin, native Bulletin replies bind to the approved parent, and the Bulletin deadline controls are deterministic. The optional Bulletin signing control stays out of the minimal test collection.

## Journey task recovery

Private Journey operation discovery supports task recovery for the owner. Journey startup recovery is bounded so a recovery pass cannot run without limit, and external captures import into Journey with explicit evidence limits rather than as unqualified results.

## Writing and distribution surfaces

The engine adds Writing API MCP operation contracts. Bounded Relay distribution and lane admission, and a bounded Telos browser driver with startup binding, integrate behind admission controls. An opt-in bounded local HTTP transport is available for callers that ask for it.

## Stability and hardening

The Index registry fails closed on unreadable state rather than proceeding on partial data. Windows startup no longer leaves stray consoles or orphan gateways, desktop startup and native review workflows are repaired, and Windows acceptance paths, cleanup census, and contention coverage are fixed. Metadata upgrade cleanup and owner ACL grants are corrected.

## Boundary

The assembled Python suite and desktop tests passed, with unsupported or intentionally excluded cases recorded as skips. These checks do not establish local-model quality uplift, live endpoint results, physical-device acceptance, or complete coverage of every product workflow. Rowan's companion is a rendered native visual, not a claim about model behavior. Installation and published artifacts require separate release verification.
