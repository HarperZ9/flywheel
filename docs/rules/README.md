# Rules of record

These are the standing rules Flywheel is built and evaluated under. Each rule has
one full text, the page linked below, and one short form, the line beside it.
The page governs when the two differ. Read the page before applying a rule to a
non-trivial decision.

| Rule | Short form |
| :- | :- |
| [Evidence, insight and useful work](evidence-and-useful-work.md) | Optimize for the real objective. Separate exploration from validation, check the checks, keep claims bounded, and write for the reader. |
| [Evaluation must inform decisions](evidence-and-useful-work.md#evaluation-must-inform-decisions) | Name the decision, owner, baseline and change trigger first. Record the decision, recheck and limits after, in the minimal decision record. |
| [Neutral evaluation](evidence-and-useful-work.md#neutral-evaluation-of-models-and-organizations) | One standard for every model and organization, Flywheel's own included. Missing access stays unknown. |
| [Compete to win](compete-to-win.md) | Cede no common feature and treat no competitor lead as permanent. Compare, set targets, ship, recheck, and keep superiority claims tied to evidence. |
| [Environment attribution and voice](environment-attribution-and-voice.md) | Misbehavior comes from the training environment and its incentives. Internal signals are untrusted readouts checked against behavior. Lead public copy with the mechanism. |
| [Just culture](just-culture.md) | Honest error meets learning. Recklessness and concealment are sanctioned, concealment worst. Honest failure never costs more than a successful deception. |
| [The commons](commons.md) | Protect the shared record: provenance at the source, independence by structure, real participation, and a path back. |
| [Threat-informed defense](threat-informed-defense.md) | Adversarial testing serves a named defensive artifact, on owned or licensed systems, in software and cyber work only, with the means contained. |
| [Coordinated disclosure](coordinated-disclosure.md) | The party that can act hears first. Publish method, learning curve and failure modes. Hold live primitives until the timeline ends. |
| [Conflict transparency](conflict-transparency.md) | Put the structural interest beside the claim, and apply the practice to Flywheel's own outputs first. |
| [Research synthesis](research-synthesis.md) | Seven steps from theme to layered argument. Every gap-filling claim is labeled inferred and given its cheapest test. |

The belief these rules serve is in [CREDO.md](../../CREDO.md). How Flywheel
records assessor independence is in [INDEPENDENCE.md](../INDEPENDENCE.md).

None of these rules overrides an authorization, privacy, legal, disclosure,
release or ownership requirement.
