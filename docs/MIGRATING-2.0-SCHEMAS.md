## Receipt codes

A 1.x receipt (`flywheel.receipt/v3` and `v4`) lists limits under
`does_not_prove`. A 2.0 receipt (`flywheel.receipt/v5`) lists what it covers
under `scope`. Each row is one receipt field. The 1.x code is present when
the limit applies, and the 2.0 code is present when the property holds, so
for most rows a receipt that had the old code lacks the new one. The first
row is the code every receipt carries, and the last row is present in both
versions under the same condition.

| 1.x code in `does_not_prove` | 2.0 code in `scope` |
|---|---|
| `NOT_PROVES_PUBLICATION_COMPLETENESS` | `CHECKED_BY_NAMED_CHECKER` |
| `NOT_PROVES_VERIFIER_SOUNDNESS` | `VERIFIER_QA_CARD_BOUND` |
| `NOT_PROVES_RESISTANCE_TO_ORACLE_GAMING` | `HELD_OUT_CHECKER_AGREES` |
| `NOT_PROVES_EXACTNESS` | `PREDICATE_EXACT` |
| `NOT_PROVES_COMPLETE_ENUMERATION` | `SEARCH_SPACE_ENUMERATED` |
| `NOT_PROVES_NOVELTY` | `NOVELTY_CHECKED` |
| `NOT_PROVES_CONTAINMENT` | `CHECKED_WITHOUT_RUNNING_CANDIDATE` |
