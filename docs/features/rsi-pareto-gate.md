# RSI Pareto Gate

The RSI Pareto gate is a pure standard library verifier that audits oracle gated recursive self improvement orchestrator runs alongside Centennial MIT WebAssembly playground packs. It enforces strict monotonic compound score progression, zero regressions, complete Goodhart trap rollback, tight three way parity agreement, and clean open source distribution hygiene in a single fail closed pass.

For the recursive self improvement report, the verifier rejects any run with non finite metrics, non positive baseline scores, compound gains below one, or arithmetic drift between initial and final scores. It enforces one hundred percent Goodhart trap blocking, zero runtime failures, three way parity error at or below one part in ten billion, and full confirmation of all planted negative controls covering Goodhart rollback, non positive budgets, and forged superoptimizer certificates.

For the Centennial WebAssembly pack, the verifier confirms top level and per module MIT licensing, exact module cardinality of one hundred distinct slugs, at least sixteen zero import modules, and a combined byte size under one point two five mebibytes. Every module path is restricted to safe relative WebAssembly paths to prevent directory traversal, and optional disk auditing verifies raw WebAssembly magic headers, exact byte lengths, and SHA256 digests directly against local binaries.

Command line invocation reads both JSON artifacts and returns exit code zero on a verified pass or exit code two on any violation. Downstream pipelines can run the gate offline with zero external dependencies and inspect the structured JSON verdict for reproducible release attestation.
