# Flywheel explainer

`index.html` is a single self-contained page that explains how Flywheel decides
whether a tool request may run and how a sealed result is rechecked. It is
published at <https://harperz9.github.io/repo-explainers/flywheel.html>.

To read it from a checkout, open `index.html` in a browser. It loads two
typefaces from harperz9.github.io and falls back to system fonts offline.

Every command, hash and verdict on the page came from running this repository
at commit 1ec701d. The page cites the file behind each step. When the code it
describes changes, rerun the commands in its "Try it" section and update the
values in the same pull request.
