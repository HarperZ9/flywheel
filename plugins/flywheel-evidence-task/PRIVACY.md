# Privacy

Flywheel Evidence Task is a skill: a set of written instructions, a constraints
reference and examples. The plugin contains no program, MCP server, hook or
script. It runs nothing on your computer and opens no network connection.

## What this plugin runs and handles

**Hooks.** This plugin has no hooks.

**MCP server.** This plugin has no MCP server and no launch command.

**Programs and scripts.** The plugin contains no program and no script. It is a skill: a SKILL.md file with instructions, one constraints reference, three examples, and a Codex presentation file (`agents/openai.yaml`). Nothing in it runs on your computer.

**Network.** The plugin opens no network connection and sends nothing to the author or to any other service.

**Files it reads.** None on its own. When you ask for a check, Claude reads the sources you name with the tools your Claude client already allows, such as file reads, web fetches or MCP servers you connected. Those tools follow their own settings and privacy terms.

**Files it writes.** None. Claude writes an evidence packet to a file only when you ask it to.

**Environment variables and credentials.** The plugin reads no environment variables and no credentials.

**Retention.** The plugin keeps nothing. Uninstalling it removes the skill files.

## What it reads

The skill reads nothing on its own. Claude reads the sources you name for a
check, with the tools your Claude client already allows, such as file reads,
web fetches or MCP servers you have connected. Those tools follow their own
settings and privacy terms.

## What it stores

Nothing. The plugin writes no file and keeps no database. An evidence packet
appears in your conversation, and Claude writes it to a file only when you ask.

## What it sends

Nothing. The plugin has no telemetry and no usage statistics, and it sends no
data to the author or to any third party. Your conversation goes to the model
provider your Claude client uses, under that provider's policy.

## Retention

The plugin retains nothing. Uninstalling it removes the skill files.

## Children

The plugin is a developer and research tool. It is not directed at children
under 18.
