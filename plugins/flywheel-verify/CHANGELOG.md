# Changelog

## 1.1.0

- First release of the Flywheel Verify plugin for Claude Code.
- One MCP server, `check`, started from the pinned `flywheel-verify` 1.1.0 package through uv.
- Three read-only tools: `check_answer`, `domain_packs`, and `verify_bundle`, each with a title and all four MCP hints.
- The `check-before-answering` skill, which tells Claude when to check a value and how to report the result.
- Sample data: a rate-card contract with a passing and a failing answer, and a demonstration receipt bundle.
- Privacy Policy section in the README.
